# Content and eligibility rules (AuraLabs Creator Circle)

1. Original or clearly disclosed AI-assisted work only. Credit tools in the submission note.
2. No copyrighted characters, studio names, or living-creator name-drops in prompts or captions.
3. No NSFW, hate, or political campaign content in program submissions.
4. One primary platform account per member; alt accounts need manager approval.
5. Country must stay visible in the public bio for the whole stipend month.
6. Rejected pieces can be revised once in the same month; a second reject closes that slot.
